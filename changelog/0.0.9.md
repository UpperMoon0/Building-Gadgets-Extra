# Building Gadgets Extra 0.0.9

## Fixed

- Remove arbitrary upper bounds on the Building Gadgets dependency across Forge 1.16.5/1.20.1 and NeoForge 1.21.1/26.1.2. Minecraft and loader requirements remain in place.
- Update the NeoForge 1.21.1 compile dependency to Building Gadgets 2 **21.1.1** (CurseForge file 9310471), and NeoForge 26.1.2 to **26.1.2.3** (file 9364350). Both releases use a new version-number scheme that the previous upper bounds rejected.
- Add CI and release contract checks that reject reintroduced dependency upper limits or stale pinned upstream build fixtures.
- Preserve compatibility metadata minimums for installations using the older Building Gadgets releases; future upstream API changes may still require a code update.

## Compatibility and update guidance

- Install the matching Minecraft/loader build of Building Gadgets Extra, Building Gadgets, PacketWeave and OpenUI MC. The unbounded dependency ranges prevent false loader rejections, but do not guarantee binary compatibility with every future upstream release.
- Update Building Gadgets Extra on the server and every connecting client together. Confirm the actual gadget UI and Copy/Paste behavior after upstream updates.

## Existing safety boundaries

- Native structure-file imports still require the Copy Paste Gadget in **Paste mode**.
- The default import limit remains a **100,000-position bounding volume** including air, with an 8 MiB compressed transfer limit and a 64 MiB decoded-NBT budget.
