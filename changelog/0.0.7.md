# Changelog

## 0.0.7 - 2026-10-14

### Added

- Added composable Array and Radial Mirror modifiers for the Builder's Multitool Building and Exchanging profiles, completing the live modifier family from issue #3.
- Added distinct custom Array and Radial icons matching the white radial-menu glyphs.
- Integrated Mirror, Array and Radial controls into the Build/Exchange profile settings. Array/Radial expand inline; valid edits save directly. Off preserves configured values, resets affect only their own stage, and composition order lists enabled stages. The settings area scrolls and the mode wheel adapts to smaller GUI sizes.
- Enabled live modifiers on Forge 1.16.5 with per-position block-state transforms for placement, preview and persisted anchors.

### Behavior and limits

- Counts include the original. Array copies translate by the selected step; Radial Mirror repeats around the vertical Y axis. Radial coordinates round to the nearest block; block facing rotates to the nearest quarter turn supported by Minecraft.
- Settings belong to the active Build/Exchange profile and are validated on the server. Steps/pivots are limited to -64..64. Duplicate positions keep their original state and incur one placement cost.
- Plans are capped at 65,536 positions. Rejected plans produce no placement candidates rather than silently performing the unmodified operation.
- Preview and execution use the same common planner and ordered state transforms. Placement retains upstream survival inventory, FE and protection hooks.
- Network protocols changed: clients and servers must update together.
- Copy/Paste imports retain the default 100,000-position bounding volume, configurable up to 1,000,000; imports still require Paste mode. Transfer/NBT budgets and Cut/Paste behavior are unchanged.

### Tests

- Added geometry, order, provenance, dedupe, overflow, settings validation and radial rounding regressions, plus cross-version runtime and client/server coverage.
