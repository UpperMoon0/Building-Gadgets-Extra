# Changelog

## 0.0.5 — 2026-09-10

### Added

- Added live **Horizontal Mirror** and **Vertical Mirror** modifiers to the Builder's Multitool in Building and Exchanging profiles on Forge 1.20.1, NeoForge 1.21.1, and NeoForge 26.1.2.
- Added a shared, Minecraft-independent operation-planner foundation for future composable modifiers such as Array and Radial Mirror.
- Added server-authoritative live-mirror toggles to the Multitool radial menu with explicit enabled/disabled feedback.
- Added cross-version contracts covering planner wiring, UI exposure, server authority, bounded plans, translations, and the intentional legacy feature gate.

### Changed

- Build/Exchange live mirroring transforms the same upstream candidate list used by preview and execution, keeping hologram and placement geometry in lockstep.
- Horizontal mirroring follows the player's facing axis; vertical mirroring reflects around the active operation anchor. Directional block states are mirrored per generated copy instead of only moving coordinates.
- Live modifier state is isolated with the active Multitool virtual-gadget profile, consistent with the Multitool's existing per-profile settings model.
- Duplicate positions are resolved deterministically and interactive plans are capped at 65,536 positions. Overflow or an oversized transformed plan fails closed to the original upstream operation instead of partially applying a modifier.
- Reused the existing mirror network action contextually rather than adding a second mirror protocol. Forge 1.20.1 and both NeoForge ports bump their addon protocol versions so mixed 0.0.4/0.0.5 peers cannot misinterpret a live-mirror request as a template mutation.

### Compatibility

- Minecraft 1.16.5 remains fully supported by the 0.0.5 artifact, but **live Build/Exchange mirroring is intentionally not exposed on that port yet**. Legacy Building Gadgets represents its build plan as positions plus one shared block state, so a coordinate-only implementation would render/place directional blocks such as stairs incorrectly after mirroring. The feature stays gated until the legacy adapter can preserve per-position transformed block states.
- Existing Copy/Paste and Cut/Paste template mirroring remains unchanged on every supported port.
