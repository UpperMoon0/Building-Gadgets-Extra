# Changelog

## 0.0.5 — 2026-10-14

### Changed

- Added the server/world `maxCopyVolume` setting for Copy/Paste selections and native structure imports. It defaults to a 100,000-position bounding volume and can be raised to 1,000,000 positions.
- Applied the copy limit to native Building Gadgets 2 Copy/Paste gadgets and the Builder's Multitool on Forge 1.20.1, NeoForge 1.21.1, and NeoForge 26.1.2. Forge 1.16.5 world copying retains upstream's `Max Copy Dimensions` and `OverrideCopySize` controls; native structure imports use the new setting.
- Air still counts toward the selection volume. Existing transfer/NBT budgets, upstream axis checks, and Cut/Paste limits remain unchanged. External imports still require Copy/Paste Paste mode.
- Documented how server owners can raise the limit in `serverconfig/buildinggadgetsextra-server.toml`.

### Testing

- Added shared boundary and overflow tests for configurable structure limits.
- Added in-game regressions for native and Multitool copying above 100,000 positions, preserving air and relative bounds, and rejecting selections after the server lowers its limit.

### Fixed

- Send BG2 copy previews in bounded 32 KiB chunks so templates up to the configured million-position maximum do not exceed the native packet/NBT limits. Validate byte budgets, geometry, palette indices and transfer identity before updating the client cache. Partial transfers expire and clear on world changes.
- Require matching updated Extra clients and server through bumped transport protocol versions.
- Added million-position wire-codec regressions and malformed-input/reassembly boundary tests on all three BG2 ports.
