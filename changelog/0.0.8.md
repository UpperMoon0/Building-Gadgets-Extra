# Building Gadgets Extra 0.0.8

## Fixed

- Prevent a production client crash when Building Gadgets 2 loads its CopyGUI on Forge 1.20.1, NeoForge 1.21.1, or NeoForge 26.1.2. The CopyGUI Mixin no longer targets a mapped vanilla input method while declared `remap=false`; it hooks BG2-owned methods instead.
- Preserve Builder's Multitool CopyGUI typed coordinate drafts across focus changes, absolute/relative mode switches, and Confirm. Synchronize every valid numeric field before BG2 converts coordinates or sends the confirmation packet; incomplete drafts do not overwrite the last valid value.
- Keep native Building Gadgets gadget coordinate-change behavior unchanged. Legacy Forge 1.16.5 does not load the modern BG2 CopyGUI mixin.

## Validation and update guidance

- Packaged JARs are checked for BG2-owned CopyGUI injection targets and for absence of the invalid vanilla `charTyped` injection. Modern real-client startup forces CopyGUI through the Mixin transformer.
- Full coordinate-edit interaction testing against a server remains a required release acceptance case; the startup and class-file checks alone cannot prove UI behavior.
- Update Building Gadgets Extra on the server and every connecting client together. Users affected by the CopyGUI crash must install the matching updated client JAR. Select the artifact for your Minecraft version and loader, and keep Building Gadgets, PacketWeave and OpenUI dependencies compatible.
